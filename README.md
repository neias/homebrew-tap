# neias/homebrew-tap

Kişisel Homebrew tap'i.

## VideoLoop

Bir videoyu kusursuz (seamless) döngüye çeviren macOS uygulaması.

```bash
brew install --cask neias/tap/videoloop
```

## VidScale

Videoları standart çözünürlük basamaklarına (240p–1080p) toplu dönüştüren macOS uygulaması.

```bash
brew install --cask neias/tap/vidscale
```
